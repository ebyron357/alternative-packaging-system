## PREAMBLE — CREATIVE DIRECTOR'S MANDATE

This is not a label refresh. This is not a derivative of anything that came before it.

ALTERNATIVE™ is being built from first principles as a category-defining brand. The product is a premium THC-infused beverage. The label must function as the primary sales mechanism in retail environments where it competes on shelf against conventional non-alcoholic beverages, premium sparkling waters, and functional drinks — not against cannabis products.

The consumer does not need to see a leaf, a dispensary aesthetic, a wellness font, or a muted earth palette to understand what this is. They need to feel desire before they understand the product. Desire first. Comprehension second. Legal compliance woven in invisibly.

This document is the production constitution. Every decision made in Illustrator traces back to a section of this plan. Nothing is designed without a documented reason. Nothing ships without passing every gate in Section 13.

## SECTION 1 — COMPLETE BRAND UNDERSTANDING

### 1.1 Brand Positioning
ALTERNATIVE™ is a super-premium adult beverage brand. The brand is beverage-first, THC-second. It occupies the same psychological shelf space as a $18 cocktail, a premium Japanese whisky, or an artisanal sparkling water — not a dispensary product, not a wellness supplement, not an energy drink.

The target consumer is a sophisticated adult (25–45) who already lives in the premium beverage space. They know what they're buying. The label does not need to explain THC to them. The label needs to make them reach for it.

### 1.2 SESSION™ Sub-Brand
SESSION™ is the low-dose, social-occasion tier. 5MG THC positions it as sessionable — equivalent in psychoactive intensity to 1–2 drinks. It is approachable, not intoxicating. The label must communicate ease, pleasure, and social confidence — not wellness, not medicine, not recreation-with-a-warning.

### 1.3 Flavor: Passion Fruit
Passion Fruit is a flavor with inherent visual and aromatic equity: tropical, vibrant, slightly exotic, luxury-adjacent (it appears in premium cocktails, high-end sparkling waters, fine dining desserts). The color story is warm gold-to-magenta, not neon, not candy. The flavor expression on the label must suggest freshness and sophistication simultaneously.

### 1.4 What This Brand Is NOT
The following aesthetics and references are explicitly excluded:
- Cannabis leaf imagery, hemp iconography, or green/brown cannabis palettes
- Dispensary or smoke shop visual language (busy layouts, aggressive THC callouts, aggressive typography)
- Supplement or nutraceutical design (clinical white, serif-heavy, medicinal)
- Energy drink design (black/neon, aggressive type, explosion graphics)
- Wellness/CBD design (soft pastels, hand-drawn botanicals, serif stacks, "clean living" language)
- Craft beer design (illustrated characters, rough textures, regional identity)

### 1.5 The 10-Foot Rule
The label must create desire from 10 feet of shelf distance. This means:
- One dominant visual impression (color field or hero graphic)
- One dominant word or wordmark readable at distance
- Zero visual clutter competing for that first impression

At 3 feet: the full brand architecture becomes legible (ALTERNATIVE™, SESSION™, flavor, dose)
At arm's length: all compliance, nutrition, and legal copy is readable at minimum 6pt

### 1.6 Brand Architecture (Hierarchy of Names)
```
ALTERNATIVE™         ← Masterbrand / House
  SESSION™           ← Product line / tier
    5MG              ← Dose / descriptor
    PASSION FRUIT    ← Flavor
    12 FL OZ         ← Volume
```

## SECTION 2 — VISUAL STRATEGY

### 2.1 Design Philosophy
The label is a luxury object first, a compliance document second. The structure borrows from:
- High-end spirits label architecture (clear hierarchy, restrained color, confident white space)
- Premium sparkling water (minimal, ingredient-forward, ingredient-as-hero)
- Fashion house branding (wordmark dominance, one strong gesture, zero decoration for decoration's sake)

### 2.2 Color Strategy

**Primary canvas:** [LOCK REQUIRED — Brand Bible]
Direction: The dominant label field should be a single saturated but sophisticated color — not a gradient rainbow, not white, not black-with-neon. Passion Fruit's natural color story points toward a deep warm gold or a rich magenta-adjacent tone. The exact Pantone must come from the Brand Bible.

**Accent / type color:** High contrast against the field — either a near-white cream or a deep near-black, not pure #FFFFFF or #000000.

**Flavor expression color:** One supporting accent used exclusively to signal Passion Fruit. Must not be used on any other SKU. [LOCK REQUIRED]

**Finish strategy:** Matte field + spot gloss or foil on the ALTERNATIVE™ wordmark and SESSION™ lockup. This creates the luxury tactile signal without adding design complexity. Exact finish to be determined with printer after press capability is confirmed.

### 2.3 Structural Visual Logic

The label is a flat wrap on a 12 oz sleek can. The canvas wraps 360°. It must be designed as a unified 360° object, not as a "front" and a "back." However, there IS a primary face (consumer-facing at retail) and secondary panels.

**Panel assignment:**
- **Front panel (primary face):** Brand architecture + flavor expression. Zero compliance here except dose callout.
- **Right panel (wrapping into back):** Nutrition Facts, Ingredient list, manufacturer info.
- **Back panel:** Extended compliance copy, age warning, state warnings, QR code, website.
- **Left panel (wrapping into front):** Remaining legal, barcode, any secondary brand messaging.

Exact panel break points determined by dieline. [LOCK REQUIRED — Canworks dieline dimensions]

### 2.4 Hero Visual Element
One of the following approaches will be selected after Brand Bible review:

**Option A — Pure Typography:** The ALTERNATIVE™ wordmark and SESSION™ logotype at scale, backed by color field alone. Zero illustration. Maximum confidence. Highest luxury signal.

**Option B — Abstracted Flavor:** A single, non-literal graphic element that evokes Passion Fruit through color and form rather than illustration. Think: a color bloom, a geometric reference to the fruit's cross-section abstracted beyond recognition, a gradient field.

**Option C — Premium Illustration:** A single, editorially-styled illustration of the passion fruit — executed at a quality level that reads as editorial (think: Aesop, Le Labo, Diptyque) not as supermarket produce packaging.

Recommendation: **Option A or B**. A purely typographic or abstractly colorist approach places ALTERNATIVE™ in the same visual category as the most premium brands in the world. Illustration risks reading as flavor-first rather than brand-first at 10 feet.

Final selection: [REQUIRES BRAND BIBLE CONFIRMATION]

## SECTION 3 — TYPOGRAPHY STRATEGY

### 3.1 Type Roles
Every typeface used on this label serves exactly one role. No typeface is used for more than two roles.

| Role | Function | Weight | Size Range |
|---|---|---|---|
| Display / Wordmark | ALTERNATIVE™ logotype | [LOCK] | Largest element on label |
| Sub-brand | SESSION™ | [LOCK] | Second largest |
| Descriptor | 5MG / PASSION FRUIT / 12 FL OZ | [LOCK] | Mid-hierarchy |
| Body / Compliance | Ingredients, legal, warnings | [LOCK] | 6pt minimum |
| Nutrition | Nutrition Facts panel | FDA-mandated (Helvetica or equiv.) | Per FDA spec |

### 3.2 Typeface Direction
[LOCK REQUIRED — Brand Bible]

Design direction pending Brand Bible confirmation, but the typographic brief is:
- **Primary display face:** A sans-serif with geometric precision and high optical weight at large sizes. Must read as designed, not default. Must be print-licensed. Candidates: custom drawn, or premium licensed geometric sans.
- **Secondary / body face:** Either a companion to the display face or a neutral grotesque that provides clean compliance legibility. Must perform at 6pt printed on a can (high-contrast, open counters, generous x-height).
- **NO:** Serif stacks that read as artisanal/craft. No display scripts. No humanist sans that reads as wellness. No system fonts.

### 3.3 Trademark Handling
™ and ® marks must be set at a consistent optical relationship to their base word. Not superscripted at default character size — manually scaled and positioned to sit at cap-height, not above it. This is a production standard, not a style preference.

### 3.4 Letterspacing
- ALTERNATIVE™: Tracked at [LOCK — Brand Bible specifies]
- SESSION™: Tracked at [LOCK]
- All-caps descriptors: Minimum +50/1000em tracking for optical stability
- Body compliance text: 0 tracking — legibility over design

### 3.5 Hierarchy Enforcement Rule
At any viewing distance, only ONE typographic element is dominant. The system self-organizes into clear tiers. No two elements compete for primacy at the same scale.

- **Expression zone (middle ~45%):** Hero visual / flavor expression / SESSION™ sub-brand

All type and graphic elements within 8mm of the left and right wrap edges receive a defined compensation treatment (slight inward shift or scale adjustment) to account for the reading angle on a cylindrical surface.

## SECTION 6 — COMPLIANCE PANEL STRATEGY

### 6.1 Compliance Philosophy
Compliance copy is not a design afterthought. It is sized, spaced, and positioned as a deliberate part of the system. The goal is: every required element is fully readable and legally unambiguous, and no element screams "cannabis product" from the shelf.

### 6.2 Required Compliance Elements (US Federal + State)

The following are expected. Final copy must be confirmed by legal counsel and/or compliance specialist for each state of distribution.

| Element | Panel | Minimum Size | Notes |
|---|---|---|---|
| THC dose per serving (mg) | Back or right | 8pt | Some states require front panel |
| THC dose per container (mg) | Back or right | 8pt | |
| "Contains THC" statement | Back | 8pt | Exact language varies by state |
| 21+ age restriction | Back | 8pt min, often symbol required | Symbol: universal age-gate icon |
| "Keep out of reach of children" | Back | 6pt minimum | |
| "For use only by adults 21+" | Back | 6pt minimum | |
| "This product has not been evaluated by the FDA" | Back | 6pt minimum | |
| State-specific warnings (CA, CO, WA, IL, MN, etc.) | Back | Per state spec | MUST come from counsel |
| Prop 65 (CA only, if applicable) | Back | Per CA spec | Counsel determines applicability |
| "Do not operate heavy machinery" / impairment warning | Back | 6pt minimum | |
| Manufacturer name and full address | Back or right | 6pt minimum | |
| Distributor name (if applicable) | Back or right | 6pt minimum | |
| Net contents: 12 FL OZ (355 mL) | Front or right | 6pt minimum, per FPLA | |
| Country of origin (if applicable) | Back | Per CBP rules | Counsel determines requirement |

### 6.3 State Distribution Map Risk
This label may need to be a multi-state master OR separate state versions. Critical decision required before production:

**Option A — Federal master with universal language:** One label designed to the strictest common compliance standard. Lower SKU complexity, potential over-disclosure in lenient states.

**Option B — State-specific versions:** One master per state variant. Higher production complexity, fully optimized compliance.

**Recommendation:** Design the layout to support Option B through Illustrator layer management. Build the master with toggle-able compliance text layers so state variants can be output from one source file without redesign.

### 6.4 Compliance Text Typesetting Rules
- Minimum 6pt on all compliance copy — NO exceptions
- High contrast against background — compliance text cannot be reversed out of a low-contrast color
- No decorative typeface on compliance copy — use the clean grotesque only
- Line spacing (leading): minimum 120% of point size for legibility
- No compliance text on a textured or patterned background without a clear field behind it

### 6.5 Age-Gate Symbol Placement
The 21+ symbol (if used as a graphic element vs. text) must be:
- Minimum 1/4 inch diameter on finished can
- High contrast
- Not decoratively modified or placed within a busy visual zone

## SECTION 7 — NUTRITION LAYOUT STRATEGY

### 7.1 FDA Nutrition Facts Panel Requirements
ALTERNATIVE™ SESSION™ is a beverage. If it is regulated as a conventional food/beverage (not a supplement), it requires an FDA-compliant **Nutrition Facts** panel (21 CFR 101.9). If regulated as a dietary supplement, it requires a **Supplement Facts** panel. Legal/regulatory counsel must make this determination before production.

**Assumed for this plan: Nutrition Facts panel (conventional beverage)**

### 7.2 Panel Specifications
The FDA mandates the Nutrition Facts panel format per 21 CFR 101.9. For a small package (label area under 40 sq in), a simplified or tabular format may be permitted. For a 12 oz sleek can, the standard vertical format is typically achievable.

Required elements in order:
```

[Serving size line]
[Servings per container]
─────────────────────
Amount per serving
Calories         [X]
─────────────────────
               %DV
Total Fat [X]g   X%
  Saturated Fat [X]g  X%
  Trans Fat [X]g
Cholesterol [X]mg  X%
Sodium [X]mg    X%
Total Carbohydrate [X]g  X%
  Dietary Fiber [X]g  X%
  Total Sugars [X]g
    Incl. [X]g Added Sugars  X%
Protein [X]g
─────────────────────
Vitamin D [X]mcg  X%
Calcium [X]mg   X%
Iron [X]mg      X%
Potassium [X]mg  X%
─────────────────────
```

All nutrient values: [LOCK REQUIRED — from manufacturer/lab analysis]

### 7.3 Nutrition Panel Typography
Per FDA regulations, the Nutrition Facts panel must use a specific type treatment:
- "Nutrition Facts" headline: Bold, specific FDA-specified weight
- Type must be legible at final printed size
- Helvetica or Helvetica Black is the FDA reference typeface — any substitute must match FDA optical requirements
- Minimum type size within the panel: 6pt (8pt preferred for the headline)

### 7.4 Nutrition Panel Placement
- Right or back panel
- Clear field — no background texture, pattern, or color bleeding through it
- White or very light field behind the panel (FDA expects high contrast for the panel itself)
- If the label background is a saturated color, the Nutrition Facts panel sits on a white or off-white inset box

### 7.5 THC Nutritional Disclosure
THC dose per serving and per container is disclosed separately from the standard Nutrition Facts panel — it does not belong inside the FDA nutrition table. It belongs in a dedicated compliance callout adjacent to or below the Nutrition Facts panel.

## SECTION 8 — QR STRATEGY

### 8.1 QR Function
The QR code on ALTERNATIVE™ SESSION™ serves multiple functions:
- Age verification gateway (consumer lands on age gate before product information)
- Brand storytelling / digital experience
- State-specific compliance information (dynamically served by state)
- Product traceability (batch, lab results link)

### 8.2 QR Destination Architecture
[LOCK REQUIRED — destination URL from client]

The URL must be:
- Short and direct (not a redirect chain that breaks)
- Mobile-optimized landing page (100% of QR scans are on mobile)
- Age-gated at the landing page level (not just a policy statement — actual gate)
- Functional before the product ships

Recommended: A vanity short URL (e.g., via Bitly or custom domain) that can be retargeted without changing the QR code. This allows the destination to be updated post-print without reprinting the can.

### 8.3 QR Technical Specifications
- **Error correction level:** H (30% data restoration — accounts for printing imperfections on a curved surface)
- **Minimum size on can:** 20mm × 20mm (larger is better for curved-surface scanning)
- **Quiet zone:** Minimum 4 modules on all sides — non-negotiable, must be respected in layout
- **Color:** Dark QR on light field — do NOT reverse QR (light on dark) unless independently tested and confirmed scannable from the curved can surface
- **Format:** Vector EPS or SVG generated from final URL — never rasterized
- **Test:** QR must be scan-tested on a physical proof curved around a can mock-up before approval

### 8.4 QR Placement
- Back panel, lower half
- Clear field — no background interference
- Minimum 3mm clear margin around quiet zone before any other design element
- Call-to-action text above QR: short (e.g., "LEARN MORE" or brand-specific CTA) [LOCK REQUIRED]

## SECTION 9 — BARCODE STRATEGY

### 9.1 Barcode Type
Standard UPC-A barcode (12-digit) for US retail.

### 9.2 Barcode Number
[LOCK REQUIRED — client provides registered GS1 UPC number]

Note: The UPC must be registered with GS1 before the barcode can be generated. If not yet registered, initiate immediately — this is a retail prerequisite.

### 9.3 Technical Specifications
- **Format:** UPC-A, EAN-13 not required unless EU distribution planned
- **Minimum bar width (X-dimension):** 0.264mm (80% magnification) — preferred 100% (0.33mm)
- **Minimum size:** 80% magnification — no smaller for can printing
- **Height:** Standard full height — no truncation
- **Color:** Dark bars on light field — NOT reversed. Bar color must achieve minimum 80% PCS (Print Contrast Signal) against background
- **Quiet zones:** Minimum 9X on left, 7X on right — respected in final layout
- **Format:** Vector, generated from verified GS1 barcode software (not drawn manually)
- **Human-readable digits:** Present below bars, minimum 8pt

### 9.4 Barcode Placement
- Left or back panel (away from seam — seam proximity distorts bars)
- Portrait orientation preferred on a sleek can (bars run parallel to can axis)
- Clear white or light field behind barcode — minimum 5mm margin to any non-background element
- Minimum 10mm from any can seam edge

### 9.5 Barcode Verification
Before final print approval, the barcode must be graded by a certified verifier. Target: ANSI/ISO Grade B or better. The printer must provide a bar code verification report with the press proof.

## SECTION 10 — LAYER STRUCTURE INSIDE ILLUSTRATOR

### 10.1 Layer Architecture Philosophy
The Illustrator file is organized so that:
- Any operator can navigate it without instruction
- State variant outputs can be generated by toggling compliance layers
- Pre-press operators can isolate each production element without touching others
- Future SKU variants (new flavors) can be derived by swapping color and flavor layers only

### 10.3 Layer Rules

- All placed images are embedded (no linked files in the final master)
- All colors are defined as swatches in the document swatch panel
- No RGB values — all colors are CMYK + named Pantone where applicable
- Spot colors defined as spot, not process
- The dieline layer is NEVER merged into the art layers

## SECTION 12 — ILLUSTRATOR AI WORKFLOW

### 12.1 Role of AI in This Production
AI-assisted tools within Adobe Illustrator (Firefly-integrated features, generative fill, etc.) and external AI generation tools are available as production accelerators, not as creative decision-makers. Every AI-generated element must pass through human creative direction before it is considered for the label.

### 12.2 Permitted AI Uses in This Workflow

| Task | Tool | Notes |
|---|---|---|
| Flavor hero visual exploration | Adobe Firefly / generative | Concept exploration only — output must be vectorized or redrawn |
| Background texture generation | Adobe Firefly | Converted to vector or high-res CMYK raster before use |
| Type pairing suggestions | AI recommendation | Human-confirmed against Brand Bible |
| Color palette exploration | AI tool | Confirmed against Brand Bible before adoption |
| Layout composition alternatives | AI layout tools | Human selection required |
| Copyediting compliance text | AI grammar check | Human legal review still mandatory |

### 12.3 Prohibited AI Uses

- AI-generated QR codes (must be generated from verified URL via proper QR software)
- AI-generated barcodes (must come from GS1-verified barcode software)
- AI-generated nutrition facts panels (must be built from actual lab data)
- AI-generated compliance copy (must come from counsel)
- AI-generated final wordmarks or logos (must match Brand Bible lockups)

### 12.4 Vectorization Requirement
Any raster asset generated by AI tools (Firefly, Midjourney, etc.) that is used in production must be:
1. Vectorized via Illustrator's Image Trace or redrawn in vector
2. OR confirmed at minimum 300 DPI in CMYK at final print size
3. Approved by Creative Director before placement in master file

### 12.5 AI-Assisted State Variant Generation
Once the master file is complete with all state compliance layers (Section 10, Layer 07), state variants can be generated semi-automatically:
1. Toggle relevant compliance sublayer to visible
2. Hide all other state sublayers
3. Run PDF export script for that state variant
4. File is automatically named with state code appended

## SECTION 14 — AUTOMATION OPPORTUNITIES

### 14.1 State Variant Output Automation
As described in Section 12.5: Once the master is built with layer-based state compliance, an Illustrator action or script can generate all state-variant PDFs from a single source file in minutes rather than hours.

**Tool:** Illustrator Script (.jsx) or Action set
**Trigger:** Manual run after any copy change
**Output:** One PDF per state, auto-named with state code

### 14.2 Batch Flavor Variant Generation
When additional SESSION™ flavors are developed, the master file structure enables rapid variant creation:
- Layer 04 (Flavor Expression) swapped for new flavor
- Layer 13 (Background) color field updated to flavor-specific color
- Layer 09 (Ingredients) updated with new ingredient text
- All other layers remain unchanged

This is not automation yet — it is structural readiness for automation.

### 14.3 Nutritional Data Population
If manufacturing produces nutrition data in a structured format (CSV, JSON), a simple Illustrator data merge or script can populate the Nutrition Facts panel automatically, reducing manual entry error.

### 14.4 Version Control via Git
The git repository already provides automated version history. Every file commit at a gate milestone creates a timestamped, attributable record of the design state.

### 14.5 PDF Preflight Automation
Adobe Acrobat Pro preflight profiles can be built once and applied to every PDF export, automatically flagging:
- RGB colors
- Images below 300 DPI
- Missing fonts
- Overprint issues
This eliminates manual pre-press checklist items and catches errors before they reach the printer.
