**Why Söhne:**
Söhne is Klim's interpretation of Akzidenz-Grotesk through the lens of mid-century German modernism. It communicates confidence without aggression, premium without pretension, editorial without coldness. It carries the warmth and authority the ALTERNATIVE™ brand requires at every scale — from a 10-foot shelf read to a 6pt compliance line on a printed can.

**Exception — FDA Nutrition Facts table body text:** Helvetica Neue Regular and Helvetica Neue Bold. This is a regulatory compliance exception, not a brand exception. The Nutrition Facts table header and label title use Söhne per the brand standard.

The following weights are approved for use in the ALTERNATIVE™ system:

| Weight Name | German Name | Role |
|---|---|---|

### 1.3 Typography Rules

1. **Typography is the primary luxury signal.** In the absence of photography and illustration, the type does all the work. Every size, weight, and spacing decision must carry intentional authority.
2. **Editorial before corporate.** Generous spacing. Confident sizes. No timid typography.
3. **Premium before trendy.** Söhne ages beautifully. Do not chase current design trends with size or weight choices that will feel dated.
4. **Beverage before cannabis.** The typography should make this look like a premium adult beverage from a storied brand — not a dispensary product, not a wellness supplement.
5. **Calm confidence over visual noise.** The hierarchy communicates through scale and weight contrast, not decoration.
6. **Strong hierarchy with generous spacing.** Level separation must be legible at arm's length. Line spacing minimum 120% of point size for all display text.
7. **Optical alignment over mathematical alignment.** Optically center display text within its container. Do not rely on Illustrator's automatic alignment for premium display elements.
8. **Maintain excellent readability at production sizes.** All compliance, ingredients, and legal copy must pass the 6pt legibility test before Phase 7 gate.
9. **Build for long-term brand recognition.** Söhne Leicht tracked wide for the tagline becomes a brand signature. Söhne Halbfett for the wordmark becomes the brand voice. Set these correctly once.
10. **All caps for brand identity levels.** Levels 1–6 are set in all caps. Flavor (Level 7) may be title case or all caps — decide at layout and lock. Compliance and legal are mixed case.

## PART 3 — DESIGN SYSTEM RULES

### 3.1 Brand Laws (from Brand Bible — locked)

1. The Hero A is sacred. Use only the approved vector. Never redraw, approximate, or substitute.
2. Matte Black is the primary canvas. It is never replaced by flavor color.
3. Metallic Gold is used sparingly and deliberately. It is never decorative.
4. Warm White type on Matte Black is the primary contrast relationship.
5. No photography, no fruit illustration, no decorative icons.
6. No cannabis imagery. No leaf. No smoke. No cannabis iconography of any kind.
7. Typography creates prestige. Söhne is the only brand typeface.
8. Whitespace is a design element, not empty space.
9. The 8-level hierarchy is inviolable. Nothing interrupts the reading sequence.
10. The brand must feel established. Every decision must serve long-term recognition.

### 3.2 Spacing Principles

- **Display type:** Optical spacing. Mathematical alignment is a starting point, not the end.
- **Tracking:** Wide tracking on light weights signals luxury. Never compress Leicht.
- **Leading:** 120% minimum for display. 130–140% for body and compliance text.
- **Margins:** Generous. White space (black space on this label) is brand equity.
- **Hierarchy gaps:** Space between hierarchy levels must be visually intentional — not uniform. Larger gaps signal more significant level breaks.

### 3.3 Prohibitions

| Action | Status |
|---|---|
| Using a typeface other than Söhne for brand text | PROHIBITED |
| Using Futura on any ALTERNATIVE™ brand element | PROHIBITED |
| Inventing CMYK values before print proof confirmation | PROHIBITED |
| Using photography or illustration | PROHIBITED |
| Using cannabis imagery | PROHIBITED |
| Compressing Söhne Leicht horizontally | PROHIBITED |
| Replacing Matte Black with flavor color | PROHIBITED |
| Falling below 6pt for any label text | PROHIBITED |
| Freeform type not assigned to a Character Style | PROHIBITED |

## PART 4 — SKU SCALABILITY

The typography system is designed to serve every future ALTERNATIVE™ SKU without redesign.

| Change Type | Impact | Action Required |
|---|---|---|
| New flavor (e.g., Lychee Sweet Tea) | CS-06 Flavor style accommodates | Update flavor copy only |
| New experience line (SOCIAL, RESERVE, ASCEND) | CS-03 Product Line style accommodates | Update product line copy only |
| New strength (10mg, 50mg, 100mg) | CS-04 THC Strength style accommodates | Update dose copy only |
| New SKU entirely | All styles carry forward | Duplicate master, update variable fields |
| New can size | Physical dimensions change | New dieline — typography system unchanged |
| New language market | Söhne supports Latin Extended | No typeface change required for most markets |

**Confirmation:** The Söhne typography system supports every currently planned ALTERNATIVE™ SKU (SESSION 5mg, SOCIAL 10mg, RESERVE 50mg, ASCEND 100mg in Passion Fruit and Lychee Sweet Tea) without any typographic redesign. Variable fields (flavor, dose, product line) are handled by copy substitution within confirmed Character Styles.

## PART 6 — PRODUCTION RISKS (TYPOGRAPHY)

| Risk | Description | Mitigation |
|---|---|---|
| PR-T01 — License not purchased | If Söhne is not licensed before production delivery, the file cannot legally be delivered to the printer. | Purchase license immediately once production is approved for delivery. |
| PR-T02 — Söhne font files not installed | Character styles cannot be built in Illustrator without Söhne font files installed on the production machine. | Install Söhne from Klim website. Confirm all required weights installed before Phase 3 Illustrator session. |
| PR-T03 — Compliance text below 6pt | Layout pressure may compress compliance text below minimum. | Gate 7 QA check includes physical measurement of all compliance type. Any element below 6pt is a blocker. |
| PR-T04 — FDA Nutrition Facts exception not preserved | Future operators may replace Helvetica Neue with Söhne throughout, violating FDA convention. | CS-17 is explicitly labeled as FDA exception. Notes in Illustrator layers warn against replacement. |
| PR-T05 — ™ symbol scaled incorrectly | Default superscript reads as typographic error at display sizes. | All ™ symbols scaled manually to cap height. Phase 7 QA checks every trademark symbol. |
| PR-T06 — Optical alignment not applied | Mathematically centered display type often reads as off-center due to letterform optical weight. | All display type optically aligned at Phase 4. Phase 7 QA reviews optical alignment before approval. |
